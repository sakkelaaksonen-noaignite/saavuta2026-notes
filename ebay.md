# ebay

Noteworthy things from eBay Accessiblity team

- ebay UI core has given good results. The usual workflow: make accessible components, tell developers to use the components or at least copy the patterns.
- no QA anymore on eBay. Makes things hard.
- 4 persons on a11y team
- no reliance on automation. Always manual testing on top of it.
- increased release cycle in eBay, assumption is release fast, fix fast. But somehow this does not reach a11y features. Challenge is keeping the accessibility in the dev loop and preventing regression.
